# FACE RECOGNITION SYSTEM

## Project Report

### 1. Introduction

The Face Recognition System is a Python-based application designed to detect and recognize human faces using a webcam.

### 2. Objective

The main objective is to develop a system that can register new faces and identify previously registered users.

### 3. Technologies Used

* Python
* OpenCV
* NumPy
* Tkinter
* Haar Cascade Classifier
* LBPH Face Recognizer

### 4. Main Features

1. Face Registration
2. Face Detection
3. Face Recognition
4. Unknown Face Detection
5. Graphical User Interface

### 5. Working Methodology

**Step 1:** The user opens the application.

**Step 2:** The user selects Register New Face.

**Step 3:** The system captures face images through the webcam.

**Step 4:** Captured images are stored in the dataset folder.

**Step 5:** The user selects Recognize Face.

**Step 6:** The system compares the detected face with registered face data.

**Step 7:** The recognized person's name is displayed.

### 6. Software Requirements

* Windows Operating System
* Python 3
* Visual Studio Code
* Webcam
* OpenCV Library

### 7. Applications

* Basic attendance systems
* Identity verification
* Face-based access control
* Educational projects

### 8. Conclusion

The Face Recognition System demonstrates how computer vision and machine learning techniques can be used to detect and recognize faces.

The project provides practical experience with Python programming, OpenCV and GUI development.
