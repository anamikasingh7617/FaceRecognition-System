# Face Recognition System

## Project Overview

This project is a Python-based Face Recognition System that detects and recognizes registered faces using a webcam.

## Features

* Register New Faces
* Capture face images through webcam
* Recognize registered faces
* Identify unknown faces
* User-friendly GUI using Tkinter

## Technologies Used

* Python
* OpenCV
* NumPy
* Tkinter
* Haar Cascade Classifier
* LBPH Face Recognizer

## Installation

Install the required libraries:

```bash
pip install opencv-contrib-python numpy
```

## How to Run

1. Clone or download this repository.
2. Install the required libraries.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```

5. Register a new face.
6. Click Recognize Face to identify the registered person.
